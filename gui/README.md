# Allagan Eye GUI

Tauri 2 + React 19 + TypeScript による L2a GUI。本ディレクトリは `#483` で bootstrap された scaffold のみを含み、画面実装は `#464-#466` で追加される。

## クイックスタート

```bash
cd gui
npm install
npm run tauri dev
```

詳細なセットアップ手順・CI 構成・アーキテクチャは [docs/gui-development.md](../docs/gui-development.md) を参照。

設計仕様は [docs/design/README.md](../docs/design/README.md)、Tauri 固有の実装知見は [docs/design/phase0-tauri-reference.md](../docs/design/phase0-tauri-reference.md) を参照。
