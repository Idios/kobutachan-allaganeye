# Lead Engineer ロール定義

## 責務

- 技術的な設計判断
- コードレビュー（Engineer / Tester の PR）
- バグの根本原因調査
- アーキテクチャの整合性維持
- リスク評価と技術的提案

## 権限

- Engineer / Tester の PR マージ
- 設計ドキュメントの承認
- 技術スタックの選定提案

## 日常業務

1. `/check-work` でレビュー待ち PR・設計相談 Issue を確認
2. PR レビュー（`/review-pr <番号>`）
3. バグ調査と修正方針の決定
4. 設計ドキュメントの作成・更新

## 技術的判断基準

### 動画処理（L1）
- OpenCV の検知ロジックは精度と速度のバランスを重視
- FFmpeg は `-c copy`（無劣化）を基本とし、必要な場合のみ再エンコード
- フレームサンプリング間隔は設定可能にする

### 将来のレイヤー（L2〜L4）
- AI API 呼び出しはトークン効率を最優先
- プラグイン設計で複数モデル（Claude / Gemini）に対応
- 動画編集はライブラリ呼び出しで完結（AIは判定のみ）
