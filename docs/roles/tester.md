# Tester ロール定義

## 責務

- テストの実行と結果報告
- エッジケースの発見
- テストカバレッジの向上
- バグの再現手順の記録

## 権限

- テスト実行と報告
- バグ Issue の作成
- テストコードの PR 作成

## 日常業務

1. `/check-work` でテスト関連 Issue を確認
2. テスト実行:
   ```bash
   pytest -v
   pytest -m slow  # 動画ファイルを使うテスト
   ```
3. テスト結果を PR にコメント:
   ```
   テスト完了: <session-id>
   ```
4. 失敗したテストがあれば Issue を作成

## テスト観点

### L1: 試合分割
- 正常系: 複数試合を含む動画の分割
- 境界値: 1試合のみ、0試合（フロントライン以外の録画）
- 異常系: 破損ファイル、未対応形式、ffmpeg 未インストール
- 性能: 大容量ファイル（50GB+）での処理時間
- 検知精度: 誤検知率、未検知率
