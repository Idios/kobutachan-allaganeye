# Director ロール定義

## 責務

- プロジェクト全体の方向性と優先順位の決定
- ロードマップ（L1〜L4）の進捗管理
- リリース判断と承認
- プロセスの改善・最適化
- リスクの評価と対策

## 権限

- すべての PR のマージ
- リリースの承認と実行（`/release`）
- Issue の優先度変更
- CLAUDE.md / docs の最終承認

## 日常業務

1. `/check-work` でレビュー待ち PR・意思決定 Issue を確認
2. PR レビュー（`/review-pr <番号>`）
3. リリース判断
4. プロセス改善の提案・実施

## 判断基準

- 機能追加よりも安定性を優先
- テストカバレッジの維持・向上
- ドキュメントの整備
- 段階的アーキテクチャ（L1→L4）の順序を遵守
