# 動画処理設計

## 概要

L1 の動画処理は以下の3段階で構成される:

1. **probe**: ffprobe で入力動画のメタデータを取得
2. **detect**: OpenCV でフレームを解析し、試合境界を検知
3. **split**: FFmpeg で試合ごとに動画を分割

## probe（メタデータ取得）

ffprobe を使用して以下の情報を取得:
- コーデック（映像/音声）
- 解像度
- フレームレート
- 総再生時間
- コンテナ形式

## detect（試合境界検知）

### フレームサンプリング

全フレームの解析はコストが高いため、一定間隔（デフォルト1秒）でフレームをサンプリングする。

### 暗転検知

フロントラインの試合間には必ずロード画面（暗転）が入る。この特性を利用:

1. フレームをグレースケールに変換
2. 平均輝度を計算
3. 閾値以下なら「暗転フレーム」と判定
4. 連続する暗転フレームの開始・終了時刻を記録

### 試合セグメント抽出

暗転区間をセパレータとして、非暗転区間を「試合候補」として抽出。
最小試合時間（デフォルト300秒 = 5分）未満のセグメントは除外する。

### 将来の拡張

- ヒストグラム比較による画面遷移検知
- リザルト画面のテンプレートマッチング
- UIオーバーレイ（HP/MPバー）の検知

## split（動画分割）

### FFmpeg コピーモード

```bash
ffmpeg -i input.mkv -ss <start> -to <end> -c copy -avoid_negative_ts make_zero output.mp4
```

- `-c copy`: 再エンコードなし（高速・無劣化）
- `-avoid_negative_ts make_zero`: タイムスタンプ補正
- キーフレーム境界での分割精度に注意（数秒のずれが発生する可能性）

### 出力命名規則

```
match_001.mp4
match_002.mp4
...
```

ゼロパディング3桁。
