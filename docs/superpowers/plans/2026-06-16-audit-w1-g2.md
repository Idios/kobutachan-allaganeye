# Audit Remediation Wave 1 — G2 (#813 GUI detect 中断 kill 配線) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: `superpowers:subagent-driven-development` (fresh subagent per task + spec/quality 2-stage review). TDD HARD-GATE (`superpowers:test-driven-development`): NO PRODUCTION CODE WITHOUT A FAILING TEST FIRST. Steps use checkbox (`- [ ]`).

**Goal:** Tauri GUI の detect「中断」が走行中の detect プロセス (Python CLI + N 本の ffmpeg 子) を kill せず phase 遷移のみで終わる (P1-1) ことと、detect イベントに run 識別子が無く旧 run の event が新 run の UI に越境混入しうる (P1-1) ことを解消する。中断時に `kill_tracked_processes` を invoke してから `CANCEL_CONFIRMED` を発火し、`start_detect` 起動ごとに frontend が払い出す run id を全 `detect-progress` payload に echo して listener が現在 run 以外の event を無視する。

**Architecture (信号経路):**

- **kill 配線**: 中断クリック → `CANCEL_CLICKED` → `cancelling` phase。`cancelling` 副作用 effect が `await invoke('kill_tracked_processes')` (失敗は log のみ、best-effort) → `dispatch(CANCEL_CONFIRMED)`。kill は既存 `kill_tracked_processes` ([lib.rs:1497](../../../gui/src-tauri/src/lib.rs)) が PROCESS_TRACKER を drain + 各 `TrackedChild` の Job handle を drop し、`JOB_OBJECT_LIMIT_KILL_ON_JOB_CLOSE` で Python CLI と ffmpeg 子孫を tree-kill (#756 で配線済)。in-flight `start_detect` は次の `untrack_child` が None を返し `subprocess.cancelled` で reject、reducer が `DETECT_ERROR during cancelling → cancelled` で吸収するため error 画面化しない。
- **run-id fencing**: `start_detect` のたびに frontend が `crypto.randomUUID()` で run id を払い出し → listen 前に closure に capture + `start_detect` param で渡す → Rust が受領し全 `detect-progress` emit (正常 4 経路) に `stamp_run_id` で echo → `DetectProgress.run_id` / `DetectProgressEvent.run_id` に追加 → listener が `run_id !== undefined && run_id !== runId` を fence。frontend 生成 = race-free (start_detect 戻り値待ち不要)。Rust が全 emit に stamp するため本番では straggler event も run id を持ち、mismatch で確実に遮断される (lenient 条件は bare event = unit test のみ通す)。

**Tech Stack:** React 19 + TS (Vitest/jsdom) / Rust (Tauri 2、tokio、serde) / cargo test。`crypto.randomUUID` は Tauri webview / jsdom (Node 25 `globalThis.crypto`) ともに利用可 (実測確認済)。

**元 issue:** #813 (P1-high, l2a-gui)。**AC は確立済み運用どおり spec §G2「受け入れ条件案」を正式 AC として逐条検証** ([docs/superpowers/specs/2026-06-10-audit-remediation-design.md](../specs/2026-06-10-audit-remediation-design.md) §G2):

1. 中断クリックで `kill_tracked_processes` が invoke される (unit)
2. 中断後に旧 run のイベントが UI に反映されない (unit)
3. 実機: 中断後に ffmpeg プロセスが残らない (Idios 実機検証)
