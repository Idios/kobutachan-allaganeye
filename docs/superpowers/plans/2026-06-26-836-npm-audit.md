# #836 gui npm 依存脆弱性解消 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** gui の npm 依存に存在する既知脆弱性 6 件を解消し `npm audit` を clean (exit 0) にする。

**Architecture:** direct devDep (vite / ajv) を exact-pin で最小 patch に bump し、残る transitive 4 件 (undici / js-yaml / brace-expansion / @babel/core) を `npm audit fix` (非 force) で in-range 解消する。`npm audit fix --force` は使わない (vite を 8.1.0 へ over-bump し Idios 選択の 8.0.16 を逸脱するため)。変更は `gui/package.json` + `gui/package-lock.json` のみで、production code・Rust・配布 bundle には触れない。

**Tech Stack:** npm (Node 20 相当) / vite / vitest / eslint / TypeScript / Tauri 2 (Rust)。CI gate は `.github/workflows/security-audit.yml` の `npm audit --audit-level=high`。

---

## 背景 (実測値、2026-06-26 時点 origin/develop-0.3.0 @ 0290a0e)

`cd gui && npm audit --audit-level=high` は現状 **exit 1** で以下 6 件を報告 (1 low / 3 moderate / 2 high):

| package | 現バージョン | 解消先 | severity | 種別 | 経路 |
| --- | --- | --- | --- | --- | --- |
| vite | 8.0.9 | 8.0.16 | HIGH | direct devDep (exact pin) | direct |
| ajv | 8.17.1 | 8.18.0 | moderate | direct devDep (exact pin) | direct |
| undici | 7.25.0 | 7.28.0 | HIGH | transitive | jsdom → vitest |
| js-yaml | 4.1.1 | 4.2.0 | moderate | transitive | (browserslist 系) |
| brace-expansion | 5.0.5 | 5.0.6 | moderate | transitive | (複数) |
| @babel/core | 7.29.0 | 7.29.7 | low | transitive | eslint-plugin-react-hooks |

- `npm audit fix` (非 force) の dry-run は transitive 4 件 (undici / js-yaml / brace-expansion / @babel/core) を in-range で解消し、vite / ajv は残す (これらは direct exact-pin のため package.json 直接編集が必要) ことを確認済み。
- バージョン方針は Idios 確定: **A 最小 patch** (vite 8.0.16 / ajv 8.18.0)。
- undici (HIGH) は issue #836 body 執筆 (2026-06-18) 後に新出した同 class の transitive advisory。AC「`npm audit --audit-level=high` exit 0」達成に必須なため (A) fold-in で取り込む。
- CI `security-audit.yml` は `gui/package.json` / `gui/package-lock.json` 変更で発火し `npm-audit` + `cargo-audit` 両 job が走る。npm-audit は HIGH のみ fail。cargo-audit は Rust 非変更のため green 維持見込み。

## Task 1: direct devDep bump + transitive audit fix (RED → GREEN)

**Files:**

- Modify: `gui/package.json` (devDependencies の `vite` / `ajv` 行)
- Modify: `gui/package-lock.json` (npm が生成)

- [ ] **Step 1: RED baseline を記録**

Run: `cd gui && npm audit --audit-level=high; echo "EXIT=$?"`

Expected: `EXIT=1`、末尾に `6 vulnerabilities (1 low, 3 moderate, 2 high)`。vite (HIGH) と undici (HIGH) が列挙される。これが「失敗するテスト」の baseline。

- [ ] **Step 2: package.json の direct devDep を exact-pin bump**

`gui/package.json` の `devDependencies` 内、以下 2 行のみを編集する (他の行・`dependencies` は触らない):

```json
    "ajv": "8.18.0",
```

(編集前: `"ajv": "8.17.1",`)

```json
    "vite": "8.0.16",
```

(編集前: `"vite": "8.0.9",`)

注意: caret (`^`) や tilde (`~`) を付けない (プロジェクトは devDep を exact pin する規約)。

- [ ] **Step 3: lock を direct bump で更新**

Run: `cd gui && npm install`

Expected: エラーなく完了。`npm install` は vite を 8.0.16、ajv を 8.18.0 に解決し package-lock.json を更新する。**`npm audit fix --force` は実行しない** (vite を 8.1.0 へ over-bump するため禁止)。

- [ ] **Step 4: direct bump 後の中間状態を確認**

Run: `cd gui && npm ls vite ajv --depth=0 2>&1 | head; echo "---"; npm audit; echo "EXIT=$?"`

Expected: vite@8.0.16 / ajv@8.18.0 が解決済み。`npm audit` は残る transitive 4 件 (undici / js-yaml / brace-expansion / @babel/core) を報告 (この時点では `EXIT` は依然非 0)。vite / ajv の advisory は消えていること。

- [ ] **Step 5: transitive を in-range 解消**

Run: `cd gui && npm audit fix; echo "EXIT=$?"`

Expected: `npm audit fix` (非 force) が undici 7.28.0 / js-yaml 4.2.0 / brace-expansion 5.0.6 / @babel/core 7.29.7 等へ in-range bump。`changed N packages`。**ここでも `--force` は付けない**。

- [ ] **Step 6: GREEN を確認 (npm audit clean)**

Run: `cd gui && npm audit --audit-level=high; echo "HIGH_EXIT=$?"; echo "==="; npm audit; echo "ALL_EXIT=$?"`

Expected: `HIGH_EXIT=0` かつ `found 0 vulnerabilities`、`ALL_EXIT=0`。1 件でも残る場合は該当 advisory の経路を `npm why <pkg>` で確認し、in-range fix があるか調べる (無い場合は STOP して controller にエスカレーション)。

- [ ] **Step 7: 変更が package.json / package-lock.json に限定されることを確認**

Run: `cd gui && git status --short`

Expected: `M gui/package.json` と `M gui/package-lock.json` のみ。他ファイルが変わっていたら STOP。

- [ ] **Step 8: vite / ajv が exact pin のままか確認**

Run: `cd gui && node -e "const p=require('./package.json');console.log('vite='+p.devDependencies.vite,'ajv='+p.devDependencies.ajv)"`

Expected: `vite=8.0.16 ajv=8.18.0` (caret / tilde 無し)。
