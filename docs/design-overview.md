# システムアーキテクチャ

## 概要

Allagan Eye は FF14 フロントラインの長時間録画動画を段階的に処理するCLIツール。

## 段階的アーキテクチャ

```
┌─────────────────────────────────────────────────┐
│  L1: 試合分割                                     │
│  入力: OBS録画 (MP4/MKV)                          │
│  処理: ffmpeg 暗転検知 → FFmpeg 無劣化分割          │
│  出力: 試合ごとの MP4 + metadata.json              │
├─────────────────────────────────────────────────┤
│  L2: メタデータ化（将来）                           │
│  入力: L1 出力の試合動画                           │
│  処理: OCR (キルログ) + 音声認識 (VC/SE)           │
│  出力: タイムスタンプ付きイベントデータ              │
├─────────────────────────────────────────────────┤
│  L3: 価値評価（将来）                              │
│  入力: L2 のイベントデータ                         │
│  処理: LLM (Claude/Gemini) による投稿価値判定       │
│  出力: スコア + 推奨アクション                      │
├─────────────────────────────────────────────────┤
│  L4: 自動編集（将来）                              │
│  入力: L3 の判定結果 + L1 の動画                   │
│  処理: MoviePy/FFmpeg で切り出し + サムネイル生成   │
│  出力: 投稿用動画 + メタデータ + 投稿提案           │
└─────────────────────────────────────────────────┘
```

## L1: 試合分割の設計

### UI変化検知

フロントラインの試合には以下の特徴的な画面遷移がある:

1. **ロード画面**: 暗転（黒画面）→ マップ表示
2. **試合中**: ゲームUI（HP/MPバー、ミニマップ、スコアボード）
3. **リザルト画面**: スコアボード、MVP表示
4. **退出後**: キャラクター画面 or 次の待機画面

### 検知戦略

- **フレームサンプリング**: 全フレームではなく、1秒間隔でサンプリング
- **暗転検知**: ffmpeg `-ss` プローブで各タイムスタンプの輝度を取得し、閾値以下なら暗転と判定
- **並列実行**: `ThreadPoolExecutor` で複数タイムスタンプを同時プローブ
- **短い暗転の除外**: リスポーン時の暗転（1-2s）を `min_blackout_duration`（デフォルト 3.0s）で除外
- **暗転内パディング**: キーフレーム誤差（~2s）で試合映像が切れないよう、カット点を暗転内にオフセット
- **ヒストグラム比較**: 連続フレーム間の色ヒストグラム差分で画面遷移を検知（将来拡張）
- **テンプレートマッチング**: リザルト画面の固定UI要素（将来拡張）

### 分割方式

- FFmpeg の `-c copy` で無劣化コピー（高速）
- キーフレーム境界で分割（暗転内パディングにより試合映像は切れない）

## 外部ツール依存

| ツール | 用途 | 必須 |
|---|---|---|
| ffmpeg 4.1+ | 動画分割・暗転検知プローブ | Yes |
| ffprobe 4.1+ | 動画メタデータ取得 | Yes |
| numpy (Python) | フレーム輝度計算 | Yes |
| OpenCV (Python) | L2 以降のフレーム解析（L1 では不使用） | No |

## AI モデル対応（将来: L3）

プラグイン方式で複数モデルに対応予定:
- **Claude API**: テキストベースの評価に強み
- **Gemini API**: 動画・画像の直接解析に強み

モデル選択はコマンド引数 or 設定ファイルで指定。
