# パラメータ調整ガイド

このガイドでは、試合の分割がうまくいかない場合の対処法を説明します。

## 推奨ワークフロー

### 1. まず `--dry-run` で検知結果を確認する

いきなり分割するのではなく、まず `--dry-run` で検知結果だけを確認しましょう。動画ファイルの分割は行われず、検知された試合の一覧だけが表示されます。

```bash
allaganeye split your_recording.mkv --dry-run
```

出力例:

```
Match 1: 02:28 - 16:30 (14m02s) → match_001.mp4
Match 2: 20:15 - 35:42 (15m27s) → match_002.mp4
Match 3: 40:08 - 55:30 (15m22s) → match_003.mp4
```

自分の録画を見返して、この結果が実際の試合の切れ目と合っているか確認してください。

### 2. 問題があればパラメータを調整する

下の「症状別の対処法」を参考に、パラメータを変更して再度 `--dry-run` で確認します。

### 3. 結果が正しければ本実行する

```bash
allaganeye split your_recording.mkv
```

---

## 症状別の対処法

### 試合の途中で分断されてしまう

**症状**: 1試合が2つ以上のファイルに分かれてしまう。

**原因**: ダウン→リスポーン時の短い暗転（1-2秒）を試合の切れ目と誤判定している。

**対処**: `--min-blackout-duration` を上げる。

```bash
# デフォルト: 3.0秒 → 5.0秒に変更
allaganeye split your_recording.mkv --min-blackout-duration 5.0 --dry-run
```

**値の決め方**: リスポーン時の暗転は通常 1-2 秒、試合間のロード画面暗転は 5 秒以上です。両者の間の値を指定します。デフォルトの 3.0 秒で多くの場合は十分ですが、分断が起きる場合は 4.0 → 5.0 と少しずつ上げてください。10.0 以上にすると本来の試合間暗転も無視される可能性があるため、上げすぎに注意してください。

**注意**: 内部的には 2パス精密計測が有効な場合、実際のフィルタリングには `min(指定値, 1.5)` が使用されます。これは精密計測（0.25s 間隔）の精度を活かし、2.0s の短い試合境界暗転も検出するためです。`--min-blackout-duration` を 1.5 以下に明示指定した場合はその値がそのまま使用されます。

---

### 別々の試合がくっついてしまう

**症状**: 2試合以上が1つのファイルにまとまってしまう。出力される試合数が実際より少ない。

**原因**: 試合間の暗転が検知されていない。ロード画面が完全な黒画面ではなく、少し明るい場合に起きやすい。

**対処**: `--blackout-threshold` を上げる。

```bash
# デフォルト: 15.0 → 25.0 に変更
allaganeye split your_recording.mkv --blackout-threshold 25.0 --dry-run
```

**値の決め方**: この値は画面の明るさを 0（真っ黒）〜 255（真っ白）で表した閾値です。この値以下の明るさのフレームが「暗転」と判定されます。

- 15.0（デフォルト）: ほぼ真っ黒なフレームだけを検知
- 20.0-30.0: 少し明るいロード画面も検知
- 40.0 以上: 通常のゲーム画面も暗転と誤判定する可能性あり

まずは 20.0 → 25.0 と 5 刻みで試し、試合が正しく分かれるところを探してください。

---

### 短い試合が出力されない

**症状**: 途中退出や途中参加で短かった試合のファイルが出力されない。

**原因**: デフォルトでは 300 秒（5分）未満のセグメントは「試合ではない」として除外されている。

**対処**: `--min-match-duration` を下げる。

```bash
# デフォルト: 300秒 → 60秒に変更
allaganeye split your_recording.mkv --min-match-duration 60 --dry-run
```

**値の決め方**: フロントラインの通常の試合は 15-20 分です。途中参加でも 5 分以上プレイしていればデフォルトで問題ありません。それより短い試合を含めたい場合は、含めたい最短の時間（秒数）を指定してください。ただし、あまり短くすると待機画面やロビーの映像も1つのファイルとして出力される場合があります。

---

### 試合が1つも検知されない

**症状**: Exit code 4 で「試合境界が見つからない」エラーになる。

**考えられる原因と対処**:

1. **動画がフロントラインの録画ではない**: このツールはフロントラインの試合間暗転（ロード画面）を検知して分割します。フロントライン以外の録画では暗転パターンが異なるため、検知できません。

2. **1試合だけの録画**: 試合間に暗転がないため、分割する境界が見つかりません。分割の必要がない録画です。

3. **暗転の閾値が低すぎる**: `--blackout-threshold` を上げてみてください（上記「別々の試合がくっついてしまう」を参照）。

4. **録画ソフトの設定**: OBS 等でシーン切替時にフェードを入れている場合、暗転が短くなることがあります。`--min-blackout-duration` を下げてみてください。

---

### 処理が遅い

**症状**: 大容量ファイル（50GB 以上）で処理に時間がかかる。

**対処**: `--sample-interval` を上げる。

```bash
# デフォルト: 1.0秒 → 2.0秒に変更
allaganeye split your_recording.mkv --sample-interval 2.0
```

**値の決め方**: この値は動画の何秒ごとにフレームをチェックするかを指定します。

- 1.0（デフォルト）: 1秒ごとにチェック。最も正確だが最も遅い
- 2.0: 2秒ごと。処理時間が約半分になる。ほとんどの場合十分な精度
- 5.0: 5秒ごと。高速だが、短い暗転（5秒未満）を見逃す可能性あり

フロントラインの試合間暗転は通常 5 秒以上あるため、2.0 秒でも精度はほぼ変わりません。10.0 以上にすると暗転を見逃す可能性が高くなるため推奨しません。

**自動調整**: `--sample-interval` を指定しない場合、動画の長さに応じて自動で調整されます（1h超→2.0s、2h超→3.0s）。明示的に指定した場合は自動調整は無効になります。

## パラメータ一覧

| パラメータ | デフォルト | 範囲 | 説明 |
|---|---|---|---|
| `--blackout-threshold` | 15.0 | 0.0 - 255.0 | 暗転と判定する明るさの上限。大きくすると検知が緩くなる |
| `--min-match-duration` | 300.0 | 0 以上 | この秒数未満のセグメントを除外する |
| `--min-blackout-duration` | 3.0 | 0 以上 | この秒数未満の暗転を無視する（リスポーン暗転の除外用） |
| `--sample-interval` | 1.0 | 0 より大きい値 | フレームチェックの間隔（秒）。大きくすると高速だが精度が下がる |

## よくある質問

### デフォルト設定のまま使っても大丈夫？

はい。デフォルト値はフロントラインの一般的な録画に合わせて調整されています。多くの場合、パラメータを変更する必要はありません。うまくいかない場合だけ、このガイドを参考に調整してください。

### 分割後の動画の画質は変わる？

変わりません。映像・音声を再エンコード（変換）せず、そのままコピーして分割するため、元の画質がそのまま維持されます。

### 分割に失敗した場合、やり直せる？

はい。再度同じコマンドを実行すれば、出力ファイルは自動的に上書きされます。途中で失敗した場合も、成功済みのファイルはそのまま残ります。
